# okf-parser 0.45.5

- Adds an optional `WikiSkillView` over canonical OKF bundle relations, with operational inventory, orphan wiki-entry detection, unevaluated skill-proposal discovery, and graph lineage queries.
- WikiSkill ergonomics reuse `Bundle.concepts`, `Bundle.links`, and `Bundle.to_networkx()`; no WikiSkill-specific parser, registry, storage, or graph is introduced.
- Exposes `wikiskill_view()` and the WikiSkill view/result types from the public Python API, with tests for inventory, lineage, and unresolved concepts.
