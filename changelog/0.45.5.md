# 0.45.5

- Add a transparent Rust fast path for canonically ordered, flat simple-scalar OKF frontmatter while retaining the full YAML parser as fallback.
- Teach the formatter to prefer `type`, `title`, `description`, then lexical remaining keys only for the same safe simple subset.
- Preserve same-host benchmark evidence showing roughly 18–21% lower end-to-end Rust load latency on 1k–50k simple-frontmatter documents.
