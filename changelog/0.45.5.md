# okf-parser 0.45.5

Documentation/RFC release; no runtime behavior changes.

- Propose RFC 0016 defining one agent-first `search` surface with compact, provenance-preserving Markdown evidence.
- Freeze offline deterministic lexical/literal Phase 1A semantics, exact body-line locations, compact/full result contracts, profile/mode rules, ranking/tie-breaking, filters, and static RFC 0008 MCP effects.
- Make local DuckDB FTS a non-blocking Phase 1B optimization and keep vector, hybrid, ANN, embeddings, and persistent materializations behind later profiles/phases.
- Align structural retrieval with RFC 0015: use the canonical document IR to select complete Markdown fragments without sending AST JSON to agents, while keeping body-line anchors explicitly ephemeral.
- Define benchmark success/quality as the validity gate and actual agent-context tokens as the primary efficiency metric.
