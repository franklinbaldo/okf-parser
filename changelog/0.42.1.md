# okf-parser 0.42.1

- propagates the release version to every manifest `verify_source` checks — the
  npm packages, the TypeScript protocol constant, the README action reference
  and the Rust crate — so a Python-only bump no longer fails the version gate
  and the release dry run;
- sorts the imports in `tests/test_relational_schema.py`, which `ruff check`
  rejects on `main`.
