# okf-parser 0.12.0

Implements the first, non-privileged phase of RFC 0003.

- adds a standard-library release contract that validates synchronized Python,
  npm, protocol, peer-dependency, changelog and optional tag metadata;
- inspects wheel, source distribution and npm archive metadata rather than
  trusting filenames alone;
- generates one manifest with package identity, byte size, SHA-256, SHA-512 and
  npm-compatible SRI integrity for the four-package release set;
- verifies safe relative paths, exact archive bytes and a matching
  `SHA256SUMS` file;
- adds unit coverage for metadata drift, incorrect tags, unexpected files,
  tampering and path traversal;
- adds a read-only `Release Dry Run` workflow for pull requests and manual refs;
- installs the exact built wheel, source distribution and npm tarballs in clean
  consumers before uploading them as a short-lived workflow artifact;
- documents local verification and the still-disabled PyPI/npm trusted-publisher
  bootstrap.

This version does not publish packages, request OIDC tokens, create tags or
create GitHub Releases.
