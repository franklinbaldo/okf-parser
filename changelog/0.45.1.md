# okf-parser 0.45.1

- Make `import --write` use the same staging-and-rename write path as other mutating operations, so an interrupted import cannot leave a partially written concept file.
- No change to OKF semantics or import conflict policy: this patch aligns the import write path with the parser's existing atomic-write guarantee.
