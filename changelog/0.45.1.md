# okf-parser 0.45.1

- Make `verify-source` enforce Rust crate identity together with the workspace version: `rust-core`, `okf-engine`, and the internal `rust-core -> okf-engine` dependency must all match.
- Add causal regression tests for drifted crate and dependency versions, closing the gap where the documented release contract allowed Rust metadata to lag behind for multiple releases.
