# okf-parser 0.24.1

- return a deterministic opaque `preview_token` from successful RFC 0005 `apply` previews;
- bind the token to the exact baseline snapshot, SQL operation, parser configuration, and physical candidate bytes;
- allow writes to require `expected_preview_token` and fail closed when the recomputed candidate differs;
- detect intervening unrelated bundle changes, candidates that become no-ops, and nondeterministic DuckDB expressions between preview and commit;
- retain the existing in-invocation whole-bundle freshness check after reviewed-preview verification;
- share exact physical rendering between candidate hashing and filesystem writes so the reviewed bytes are the bytes committed.
