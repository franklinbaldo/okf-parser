# okf-parser 0.31.0

- Python now exposes `ingest_documents`, an ordered iterator of lightweight `DocumentEnvelope` records.
- TypeScript now exposes `ingestDocuments`, an ordered async iterator using the bounded read-ahead introduced in 0.30.0.
- Callers select `identity`, `body`, `frontmatter`, and `markdown_facts` capabilities; unrequested body, metadata, and facts are not retained.
- Identity-only ingestion performs discovery and file metadata reads without opening, decoding, or parsing document content.
- Per-file decode and frontmatter failures remain isolated in their document envelope.
- Existing `load_bundle` and `loadBundle` APIs remain unchanged as compatibility façades.
