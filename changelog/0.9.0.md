# okf-parser 0.9.0

Adds a production-oriented MCP adapter to the TypeScript package.

- exposes `check`, `inventory`, `graph` and `schema` as read-only MCP tools;
- keeps business logic in the existing core and schema modules;
- returns structured JSON alongside readable text when a tool result is an
  object;
- exposes the server factory through `okf-parser/mcp` and adds the
  `okf-parser-ts-mcp` stdio binary;
- uses the official MCP TypeScript SDK v1 line while v2 remains pre-stable;
- tests tool discovery, structured calls, recoverable tool errors and the built
  stdio binary with the official client;
- exercises the installed MCP binary from an npm tarball in clean Node 22 and
  Node 24 consumer projects.
