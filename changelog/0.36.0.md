# okf-parser 0.36.0

- add public/service `preview_concept_edit` and `write_concept_edit` for bounded body-only editing of one existing concept;
- require canonical `expected_source_digest` so stale editor forms fail closed instead of overwriting newer source;
- preserve authored frontmatter text, BOM and newline convention while replacing only the Markdown body;
- return exact candidate `source_digest` and `parsed_digest` during preview;
- extract coherent snapshotting, physical reconstruction, candidate staging, validation and whole-bundle freshness checks into package-internal `write_support.py` shared by `apply` and `edit`;
- reconcile that shared writer with the current linear frontmatter scanner and canonical digest identities rather than keeping apply's historical regex splitter/reparse path;
- keep transport out of the core contract as required by #65: no GraphQL/MCP/REST choice is introduced here.
