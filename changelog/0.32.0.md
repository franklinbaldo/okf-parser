# okf-parser 0.32.0

- Adds the first optional `okf-core` Rust MVP with a narrow batch boundary from Markdown text to links and headings.
- Python and TypeScript can opt into one coarse Rust subprocess per bundle load; the default remains the existing portable native implementation.
- Full bundle output is checked for equality before benchmark timing, including concepts, reserved documents, links, and diagnostics.
- Rust does not own filesystem traversal, reads, YAML, cancellation, validation, link resolution, or relational materialization.
- A dedicated CI job formats and tests the Rust crate.
- Reproducible 10K-document benchmark evidence is recorded under `benchmarks/results/`.
