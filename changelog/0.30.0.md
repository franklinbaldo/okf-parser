# okf-parser 0.30.0

- TypeScript bundle loading now overlaps up to 32 pending UTF-8 reads while preserving deterministic path-order processing.
- Programmatic callers may set a bounded `readConcurrency` from 1 through 256; 32 is the measured default.
- Read-ahead remains bounded and feeds the existing parser one document at a time; it never retains a corpus-wide `Promise.all` result.
- Cancellation and per-file read/decode diagnostics keep their existing public behavior.
- An aborted signal is checked before initial admission and after every completed read, so cancellation never replenishes the pending-read window.
- On the documented 5,000-concept warm-cache benchmark, full TypeScript bundle loading fell from 997 ms to 791 ms.
