# okf-parser 0.13.0

Adds the public registry-state phase of RFC 0003 without enabling publication.

- classifies PyPI, the main npm package and the DuckDB npm adapter as absent,
  present with expected bytes, conflicting or unverifiable;
- compares PyPI wheel and source-distribution SHA-256 digests with the tested
  release manifest;
- compares npm distribution SRI integrity with the exact packed tarballs;
- distinguishes an absent target version from an entirely unregistered package
  name to support the one-time bootstrap decision;
- emits an explicit resumable plan using `publish`, `skip` or `block` actions;
- fails closed on conflicting, incomplete, malformed or unavailable registry
  responses;
- covers absent, complete, partial, conflicting and unverifiable states with
  deterministic fixtures;
- records the read-only preflight report alongside dry-run release artifacts.

This version still has no registry write permission, OIDC publication job,
protected release environment, tag trigger or GitHub Release finalizer.
