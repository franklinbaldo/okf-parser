# okf-parser 0.44.0

- Expose parser-owned concept records for application-facing lookup by concept id or in-bundle Markdown path.
- Expose validated structured frontmatter from `ConceptRecord`.
- Add generic frontmatter resource-relation resolution with optional target-type filtering, so consumers do not reparse Markdown or implement bundle containment themselves.
