# okf-parser 0.21.0

- `Bundle.compile_types(spec_template)` exposes the same RFC 0006 typed-table compiler used by persistent DuckDB export as live Ibis relations (#51).
- `TypedRelations` owns its ephemeral DuckDB/Ibis backend, supports context-manager cleanup, deterministic type iteration and `typed[concept_type]` lookup.
- Declared DuckDB logical types remain visible through the returned Ibis table schema and typed query results; raw-plus-typed semantics are unchanged.
- Bundle diagnostics remain separately inspectable, while declaration/materialization failures continue to raise their existing structured exceptions.
- A bundle with no declarations returns an empty typed relation set rather than creating a second inferred type system.
- The public lifecycle and typed-query contract is covered by dedicated integration tests inside the full 346-test Python suite.
- The API compiles only the strict authored OKF bundle; source-adapter policy remains outside this in-process typed layer.
- No MCP tool was added for live Ibis handles: MCP stays on serializable service operations and continues to rely on FastMCP for transport/schema behavior.
