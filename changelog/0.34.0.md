# okf-parser 0.34.0

- add `source_digest = sha256:<hex>` for the exact valid UTF-8 source and `parsed_digest = okf-parsed-v1-jcs-sha256:<hex>` for the parsed frontmatter/body value;
- canonicalize parsed values with the RFC 8785/JCS UTF-16 object-key ordering/string rules over OKF's null/string/list/object frontmatter subset and LF-normalized body;
- preserve physical differences such as BOM/CRLF in `source_digest` while making those variants converge in `parsed_digest`;
- expose both identities on parsed concepts, canonical Bundle `concepts`, Python and TypeScript DuckDB normalized relations, and opt-in `inventory --digests`;
- add `digests` to the capability-driven Python/TypeScript document envelope without making identity-only ingestion open file content;
- preserve the optional Rust core boundary: Rust still computes only Markdown links/headings, while native and Rust bundle loads expose identical digests;
- keep historical Revision identity and Markdown/editorial semantic equivalence explicitly outside this digest contract.
