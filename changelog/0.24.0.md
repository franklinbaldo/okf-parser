# okf-parser 0.24.0

- add explicit `preview_concept_edit` and `write_concept_edit` services for one existing concept body;
- require the exact `source_digest` opened by the caller so stale browser state fails closed instead of overwriting a newer file;
- stage the candidate bundle, reject newly introduced normative diagnostics, and reuse the same whole-bundle freshness checks and write machinery as relational `apply`;
- preserve authored frontmatter text, BOM and newline convention while replacing only the Markdown body;
- return candidate source and parsed digests during preview so adapters can present the exact state that a successful commit would produce;
- reject body strings that cannot be encoded as valid UTF-8 before filesystem staging.
