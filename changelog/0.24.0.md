# okf-parser 0.24.0

- The TypeScript TypeContract can now retain a lossless declared DuckDB logical type independently from its target-facing scalar projection.
- Adapters may supply declared types scoped by concept type and field path; explicit casts retain precedence and declarations never bleed across types.
- Declared-but-absent fields remain optional contract fields instead of disappearing from schema output.
- JSON Schema preserves `x-okf-duckdb-type`, decimal scale, UUID and temporal distinctions; Zod preserves safe/unsafe integer, decimal and temporal policies.
- The core still does not discover or execute trusted `.schema.sql`; that responsibility belongs to the optional DuckDB adapter in the next stacked slice of #69.
