# okf-parser 0.19.1

## RFC 0001 reconciliation

RFC 0001 is rewritten around the architecture that now exists after RFC 0006.

- `TypeContract` remains the single language-neutral schema IR;
- the first code-generation target becomes `schema --format pydantic`;
- JSON Schema, Zod, dynamic Pydantic and generated Pydantic source are required to share the same contract;
- no second `ContractGraph`, `codegen` command hierarchy or `OKFProfile.fields` format is introduced;
- Python-to-OKF generation is deferred to a separate RFC because declaration authority now needs to account for `.schema.sql` and exact DuckDB types;
- the first implementation is intentionally stdout-only and deterministic rather than adding another filesystem ownership/check subsystem.
