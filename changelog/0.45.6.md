# 0.45.6

- Avoid redundant full-document source copies in the Rust loader by consuming loaded concept documents by value.
- Reuse canonical LF source text directly and allocate newline-normalized text only when carriage returns are present.
- Preserve same-host end-to-end benchmark evidence showing 3.5% to 8.0% lower load latency as document bodies grow from 64 B to 16 KiB.
