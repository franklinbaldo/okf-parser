# okf-parser 0.41.0

- ships the release-matched `okf-core` through an optional Linux x64 npm companion package;
- lets ordinary `loadBundle()` discover the installed native package automatically;
- keeps the portable TypeScript fallback when no compatible native package is available;
- compiles Rust only in release automation, never during npm install or application startup.
