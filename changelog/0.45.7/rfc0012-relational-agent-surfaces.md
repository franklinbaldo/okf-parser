- Propose RFC 0012: one canonical relational read service over OKF concepts, links, reserved documents and diagnostics, with structured lookup/relation/diff/impact/context consumers shared by CLI and MCP. The contract keeps provider-owned identity, separate source/parsed digests, snapshot-aware impact semantics, hard context bounds and disposable backend-specific caches while allowing native RFC 0010 table functions to become a parity-tested provider when available.
