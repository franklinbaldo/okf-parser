# okf-parser 0.42.8

- hardens wheel production by pinning maturin 1.14.1 and enabling its PyPI
  compatibility preflight on every platform wheel;
- builds and executes the Linux aarch64 wheel on a native GitHub arm64 runner,
  so all five published wheels now pass a real install, `check`, DuckDB export,
  and SQL result assertion before publication;
- reuses the already-built manylinux x86_64 executable byte-for-byte for the
  `okf-parser-native-linux-x64` npm package instead of compiling a second native
  binary during release collection, and verifies both copies have identical
  SHA-256 identity;
- brings that npm-native tarball under the immutable release manifest and source
  version contract, including the parser's exact optional native dependency;
- makes Rust warnings a CI failure with workspace-wide Clippy and removes the
  stale `Serialize` import exposed by the DuckDB unlinking;
- strengthens pre- and post-publication smokes to query the generated DuckDB
  database, and expands public-index verification to all five native runner
  architectures.
