# okf-parser 0.40.0

- ships `okf-core` inside the Linux x86-64 Python wheel and npm parser tarball;
- retags the Python wheel as platform-specific while leaving the sdist as the portable fallback;
- makes the npm resolver select a platform/architecture-specific package-local binary;
- validates installed artifacts by calling the ordinary public loader without a binary path;
- keeps unsupported platforms on the same Python/TypeScript API through their portable engines.
