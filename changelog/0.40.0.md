---
type: Release
title: okf-parser 0.40.0
description: Ship the Rust okf-core as an automatically selected Python companion wheel
---

- Add `okf-parser-native`, with a platform-specific wheel containing `okf-core` and a portable fallback wheel for unsupported platforms.
- Make the Python resolver discover a companion executable installed in the active interpreter's scripts directory before consulting environment overrides or `PATH`.
- Extend release validation with a fresh-install smoke test proving ordinary `load_bundle()` selects the packaged Rust engine without application deployment configuration.
