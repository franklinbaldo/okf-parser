# okf-parser 0.40.0

- ships the `okf-core` native engine inside supported Python and npm release artifacts;
- makes plain `load_bundle()` and `loadBundle()` use packaged Rust automatically on Linux x64;
- keeps source distributions and unsupported platforms on the existing portable fallback;
- verifies package-local binary discovery through fresh-install Release Dry Run smoke tests;
- preserves one application API while making native deployment an `okf-parser` release concern.
