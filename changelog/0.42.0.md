# okf-parser 0.42.0

- adds RFC 0007 bundle-level relational schemas via explicitly trusted `okf.schema.sql`;
- validates `PRIMARY KEY`, `UNIQUE`, and cross-type `FOREIGN KEY` constraints against original OKF frontmatter;
- enables natural-key 1:N models such as `Regra(nome)` to `Fundamentacao(regra)` without embedding child records.

- exposes the trusted bundle relational contract through `check --relational-schema` and the shared Python/MCP validation surface.
