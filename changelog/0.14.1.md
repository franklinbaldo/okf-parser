# okf-parser 0.14.1

## Coverage measurement in CI

- `pytest-cov` runs alongside the existing test job, reporting per-module
  coverage and failing the build under 85%;
- current coverage is 90%, so the threshold is a regression guard, not a new
  target to hit.

## CLI and MCP command reference

- adds `docs/cli.md`, documenting every CLI command and its MCP tool
  counterpart (flags, exit codes, and where the two surfaces diverge, such as
  `duckdb` and `format --write` having no MCP equivalent because MCP tools are
  read-only).

## Documentation fix

- RFC 0002's frontmatter said `status: proposed`; the TypeScript sibling it
  proposes has been implemented, tested and shipped since 0.9.0, so the status
  now reads `accepted`.
