# okf-parser 0.15.3

## Consolidation before the next RFC 0006 milestone

No new architecture or command is introduced in this release.

- update `docs/cli.md` to document the current Python CLI, including `import`,
  `init`, `apply`, and `schema --spec-template`;
- state the intentional boundary between the full CLI and the read-only MCP
  surface instead of implying feature parity where none exists;
- close stale repository work that has already been implemented or superseded,
  so open PRs and issues describe actual remaining work.

This keeps the repository state legible before the next RFC 0006 work on
lossless declared DuckDB types and typed materialization.
