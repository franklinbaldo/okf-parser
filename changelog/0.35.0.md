# okf-parser 0.35.0

- add `import --on-conflict verify-identical` to distinguish idempotent replay from reuse of the same derived id with different content;
- reuse canonical 0.34 `parsed_digest` for equality instead of maintaining a second structural comparison or canonicalizer;
- ignore incidental YAML key order and equivalent scalar quoting while failing closed on extra/null frontmatter, unexpected body, malformed documents or any other parsed-value divergence;
- abort a mixed batch before writes when any existing destination conflicts, while reporting matches separately as `matched_existing`;
- keep `--overwrite` mutually exclusive with `verify-identical` and preserve historical `skip` as the default;
- expose the policy through the existing service, CLI and FastMCP import preview/write pair with no new tool.
