# okf-parser 0.42.4

- fixes `okf-parser --version` printing `0.0.0` instead of the real
  package version (#157). `#[command(version)]`'s bare shorthand resolves
  `CARGO_PKG_VERSION` through `clap_derive`'s own `env::var` lookup at
  macro-expansion time, which silently omits the version method entirely
  if that lookup ever comes back empty rather than embedding a value —
  no compile error, no warning. Setting `version = env!("CARGO_PKG_VERSION")`
  explicitly uses Rust's own built-in macro instead, which cannot silently
  no-op: it either embeds the real value or fails to compile.
