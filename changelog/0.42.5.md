# okf-parser 0.42.5

- fixes the actual `okf-parser --version` regression left open by 0.42.4
  (#157). The 0.42.4 fix corrected `#[command(version)]` in
  `rust-core/src/main.rs`, which is real but only affects the three hidden
  `__engine-*` subcommands the Rust binary handles itself. Every other
  invocation, including the public `--version` flag, is forwarded verbatim
  to `python -m okf_parser.cli` by `python_cli()`. Running a module with
  `python -m` sets that module's `__name__` to `"__main__"`, which breaks
  cyclopts' frame-introspection-based automatic version detection in
  `App(...)` — every fallback strategy fails silently and it returns its
  hardcoded default, `"0.0.0"`. `src/okf_parser/cli.py` now passes
  `version=importlib.metadata.version("okf-parser")` to `App(...)`
  explicitly, which resolves from installed package metadata and does not
  depend on how the module was invoked.
