# okf-parser 0.27.0

- Python and TypeScript now collect links and headings from one CommonMark tokenization behind their existing public helpers.
- Reserved log validation reuses one facts result for title and chronological date checks instead of parsing the same body twice.
- Concept link projection uses the same combined facts primitive, giving future Markdown-derived validations one internal path.
- Observable link and heading order, fenced-code handling and public API shapes remain compatible.
