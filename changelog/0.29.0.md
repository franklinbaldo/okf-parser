# okf-parser 0.29.0

- Python frontmatter parsing now uses PyYAML's safe LibYAML loader when available, with a pure-Python safe fallback, while preserving the existing string-scalar, merge-key and validation contract.
- Repeated identical Markdown targets in one document reuse a single containment resolution without collapsing authored link occurrences.
- On the documented 5,000-concept warm-cache benchmark, full Python bundle loading fell from 3,246 ms to 2,135 ms.
- Public bundle, relation, diagnostic and parser API shapes remain compatible.
