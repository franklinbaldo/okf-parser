# okf-parser 0.23.0

- The TypeScript package now exports immutable `ContractNode`, `FieldContract`, and `TypeContract` structures instead of keeping its schema IR private.
- `compileTypeContracts(root, options)` provides the application-facing compiler; `compileBundleTypeContracts(bundle, options)` lets adapters reuse an already loaded canonical bundle.
- JSON Schema and Zod continue to consume the same compiler, so the public API does not create a second schema authority.
- Deterministic ordering, requiredness, nullability, literal authored type, naming-collision failures, and strict casts retain their existing behavior.
- This is the first implementation slice of #69 and the TypeScript runtime parity gate in #68; declared RFC 0006 physical types remain for the next stacked PR.
