# okf-parser 0.41.1

- restores the tag-driven production release workflow described by RFC 0003;
- publishes the exact Python, TypeScript, DuckDB-adapter and native companion artifacts verified by the release build;
- publishes native companions before packages that depend on them;
- uses PyPI and npm trusted publishing through GitHub OIDC;
- gates publication behind the `release` GitHub environment and finalizes the GitHub Release only after registry publication succeeds.
