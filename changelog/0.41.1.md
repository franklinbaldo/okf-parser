# okf-parser 0.41.1

- restores the tag-driven production release workflow described by RFC 0003;
- builds Python, TypeScript, DuckDB-adapter and native companion artifacts once and publishes those tested bytes;
- publishes native companions before packages that depend on them;
- uses PyPI and npm trusted publishing through GitHub OIDC instead of long-lived registry tokens;
- gates publication behind the `release` GitHub environment and creates the GitHub Release only after registry publication succeeds.
