# okf-parser 0.11.0

Completes the first-class TypeScript capability set with a native Markdown
formatter built exclusively on public syntax-tree APIs.

- adds pure `formatMarkdown()` and structurally guarded `safeFormatMarkdown()`
  functions;
- adds `formatPath()` with read-only checking and explicit transactional-style
  tree writes;
- exposes `okf-parser-ts format PATH [--write]`;
- parses and serializes CommonMark, GFM and YAML frontmatter through mdast;
- increments ordered-list markers without zero-padding and keeps adjacent lists
  structurally distinct;
- protects list starts, table alignment, code metadata and content, raw HTML,
  frontmatter and block nesting before applying a rewrite;
- skips non-UTF-8 files and structurally unsafe candidates without touching
  excluded paths or symlinks;
- shares a behavioral formatting corpus between pytest and Vitest;
- validates idempotence, filesystem safety and package-level CLI behavior on
  Node 22 and Node 24.
