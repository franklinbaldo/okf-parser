# okf-parser 0.5.1

Adds RFC 0002, which proposes a first-class TypeScript implementation alongside
the Python package. The design makes observable behavior, structured diagnostics
and a shared conformance corpus the compatibility boundary, while allowing each
runtime to use its native libraries and internal architecture.

The proposed npm identity is the unscoped package `okf-parser`, paired with the
`okf-parser-ts` executable, so publication does not depend on ownership of a
personal or organization scope.

This release contains the architecture decision only. It does not add a Node.js
package or change the existing Python runtime behavior.
