# okf-parser 0.30.1

- RFC 0009 proposes an optional Git source adapter that projects commit objects into canonical OKF records without changing strict filesystem parsing.
- Commit messages use a subject-first `--- okf` envelope so ordinary Git and GitHub retain a useful subject while authored metadata and Markdown body remain structured.
- Git object facts, authored metadata, derived policy and Git Notes retain separate provenance.
- The proposal defines bounded deterministic traversal, explicit incomplete-history diagnostics, Python/TypeScript conformance and an Astro virtual-content dogfood path.
- Issues #86 through #91 track the architectural decision and implementation slices.
