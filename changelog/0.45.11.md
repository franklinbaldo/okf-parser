# 0.45.11

- Add `okf-parser materialize` to deterministically generate disposable
  `index.md` and `log.md` projections from authored OKF concepts.
- Treat OKF as the sole source of truth: log dates come only from explicit
  frontmatter, never Git history or filesystem metadata.
- Keep materialization read-only by default; `--write` explicitly persists
  the views and ensures root-relative ignore entries. Write-mode output reports
  compact deterministic digests and byte counts instead of embedding both files.
- Percent-encode Markdown-sensitive path characters in generated links and cover
  repeated materialization with an explicit idempotency test.
