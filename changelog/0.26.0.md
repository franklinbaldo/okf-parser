# okf-parser 0.26.0

- `openOkfSession` owns one ephemeral DuckDB connection and one canonical loaded Bundle, then reuses that same snapshot for normalized `okf.*` tables, RFC 0006 declaration discovery, and typed `okf_types.*` relations.
- Declared fields keep compiler-owned raw carriers beside DuckDB `TRY_CAST` projections, matching Python when an authored lexeme is invalid: the raw value survives while the typed value becomes `NULL`.
- Undeclared scalar fields remain `VARCHAR`; undeclared structured fields stay outside the typed column surface, matching the Python materialization plan.
- RFC 0006 table and column comments survive materialization and overwrite when a replacement declaration omits them.
- The session exposes the official `DuckDBConnection` for parameterized application queries rather than recreating Ibis or another query abstraction in TypeScript.
