# okf-parser 0.26.0

- Python and TypeScript now locate strict YAML frontmatter delimiters with a bounded linear scan instead of matching the whole document with a regular expression.
- The existing OKF YAML semantics, public parsing APIs, BOM handling, body preservation, aliases, merge keys, scalar spelling and diagnostics remain unchanged.
- Shared regression coverage pins CRLF input, horizontal delimiter padding, inline triple dashes, body delimiters and malformed closing lines.
- Begins #73 without introducing a third semantic implementation or committing to a Rust core.
