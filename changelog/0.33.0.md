# okf-parser 0.33.0

- add `openOkfSession` / `OkfDuckDbSession` around one canonical TypeScript `Bundle` and one owned DuckDB connection;
- materialize normalized `okf.*` relations and declared `okf_types.*` tables from that same loaded Bundle;
- preserve compiler-owned raw carriers and populate declared physical columns with DuckDB `TRY_CAST`, matching Python fail-soft typed projection semantics;
- preserve undeclared scalar fields as VARCHAR while excluding undeclared structured values;
- preserve RFC 0006 table and column comments and transactional replacement behavior;
- expose the official `DuckDBConnection` for parameterized application queries instead of imitating Ibis in TypeScript;
- forward current loader controls including bounded `readConcurrency`, cancellation and optional `rustCore`, so the session composes with the 0.30-0.32 ingestion/performance architecture.
