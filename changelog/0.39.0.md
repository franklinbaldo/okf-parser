# okf-parser 0.39.0

- make the public Python and TypeScript bundle loaders select the best available Rust engine automatically;
- keep `engine="native"` as an explicit portable/debug escape hatch;
- preserve explicit Rust executable overrides while preferring future package-local binaries, then `OKF_CORE`, then `PATH`;
- fall back to language-native implementations only when auto-discovery finds no Rust engine;
- never silently switch engines after a discovered Rust process fails;
- add deterministic resolver tests in Python and TypeScript.
