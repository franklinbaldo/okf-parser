# okf-parser 0.45.3

Release-pipeline only; no change to the package, the public API, the CLI, or the protocol.

- Stop the post-publication smoke job from failing on the macOS runners. `rustup self uninstall -y` answers "self-uninstall is disabled for this build of rustup" on their Homebrew rustup and exits 1, which killed both macOS jobs of the 0.45.2 run before `pip` ever ran and left the GitHub Release unfinalized. The removal is now best-effort and the guarantee it stood for — that a missing or incompatible wheel must fail loudly instead of silently compiling from source (#147) — is enforced directly by `pip install --only-binary=:all:`, on every platform rather than only where rustup happens to be removable.
- Replace the fixed `sleep 30` before the public-index install with a poll of the PyPI release endpoint, up to five minutes. The 0.45.2 run published correctly and then failed with "Could not find a version that satisfies the requirement": the files were on PyPI but the simple index the runner read had not caught up yet.
- Correct the 0.45.2 changelog, which claimed the restored executable bits reach consumers of the source distribution. Maturin normalizes sdist file modes to `644`; the bits apply to the repository and to clones.
