# okf-parser 0.45.3

- Drafts RFC 0017, the `fact` profile, scoped explicitly to native `.fact/`
  contexts so plain OKF keeps the identity, reserved filenames and vocabulary
  the base format and RFC 0012 already pin.
- Reconciles the profile's stable fact identity with RFC 0012 by defining
  `.fact/` as a distinct provider rather than a reinterpretation of the
  filesystem provider.
- Adds `examples/minimal`, the smallest bundle `check` accepts as conformant,
  validated by the repository's own `okf-parser check .` run.
