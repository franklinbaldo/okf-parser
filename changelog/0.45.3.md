# okf-parser 0.45.3

Release-pipeline only; no change to the package, the public API, the CLI, or the protocol.

- Stop the post-publication smoke job from failing on the macOS runners. `rustup self uninstall -y` answers "self-uninstall is disabled for this build of rustup" on their Homebrew rustup and exits 1, which killed both macOS jobs of the 0.45.2 run before the package install and left the GitHub Release unfinalized. The Rust-removal step is no longer needed: the smoke now installs with `uv pip install --only-binary :all:`, which directly forbids source distributions and therefore makes a missing or incompatible wheel fail loudly on every platform (#147), regardless of whether a Rust toolchain is present.
- Replace the fixed `sleep 30` — and the intermediate JSON-endpoint probe — with retries of the actual `uv pip install` against the public index, using `--no-cache`, for up to five minutes. The 0.45.2 run published correctly and then failed with "Could not find a version that satisfies the requirement": the files were on PyPI but the Simple API view read by the installer had not caught up yet. Retrying the real install tests the same path that must eventually succeed instead of inferring readiness from a different endpoint.
- Use `uv venv` and `uv pip` in the release smoke paths where `uv` is available, keeping environment creation and package installation on the repository's preferred Python toolchain.
- Correct the 0.45.2 changelog, which claimed the restored executable bits reach consumers of the source distribution. Maturin normalizes sdist file modes to `644`; the bits apply to the repository and to clones.
