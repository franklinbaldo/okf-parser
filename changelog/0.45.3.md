# okf-parser 0.45.3

- Adds a specification document for every concept type this repository uses, at
  the `docs/types/{slug}.md` path `--require-spec` derives.
- Promotes the rule to a normative CI gate, so `--require-spec` and
  `--normative-spec` are exercised by the project that ships them rather than
  only by their tests.
- Migrates `changelog/0.1.0.md` through `0.4.0.md` from `ChangelogEntry` to
  `Release`. The two types described the same documents in the same directory
  with the same fields; the split was drift from the 0.5.0 rename.
