# okf-parser 0.7.0

Makes schema scalar inference a language-neutral contract shared by the Python
and TypeScript implementations.

- replaces pandas and JavaScript runtime coercion heuristics with exact lexical
  classification;
- validates real calendar dates and bounded datetime components without local
  timezone behavior;
- treats arbitrarily large numeric exponents as numeric lexemes without first
  converting them to finite machine numbers;
- preserves the explicit widening policy in both runtimes: integers may be cast
  as numbers, and dates may be cast as datetimes;
- adds one shared corpus for classification and explicit-cast compatibility;
- keeps schema exporters experimental until their normalized output corpus is
  shared as a separate contract.
