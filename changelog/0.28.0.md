# okf-parser 0.28.0

- Deterministic benchmark harnesses now emit the same JSON result shape for Python and TypeScript.
- The default matrix covers 100, 1,000 and 5,000 concepts with a warm-up and median measured rounds.
- Measurements separate frontmatter boundaries, in-memory document parsing, Markdown links, Markdown headings and full filesystem bundle loading.
- Benchmark results remain observational evidence rather than a flaky CI latency threshold; same-machine repetition is required before a Rust-core decision.
