# okf-parser 0.38.0

- promotes `okf-core` from a Markdown-facts experiment to end-to-end bundle ingestion;
- moves discovery, bounded parallel reads, YAML/frontmatter, validation, link resolution,
  and source/parsed digests into the native engine;
- adds direct embedded-DuckDB materialization for concepts, reserved documents, links,
  and diagnostics;
- makes the Python and TypeScript `rust_core` options delegate the complete load while
  preserving their portable native fallbacks;
- retains the original batch facts protocol for compatibility.
