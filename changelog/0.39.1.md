# okf-parser 0.39.1

- extracts DuckDB-independent OKF semantics into the reusable `okf-engine` Rust crate;
- keeps `okf-core` as the existing CLI/JSON/direct-DuckDB compatibility facade;
- preserves the current engine implementation byte-for-byte behind a re-export shim;
- introduces a Cargo workspace so future DuckDB extension code can link the semantic engine directly;
- adds a dedicated workspace CI gate for engine and CLI tests.
