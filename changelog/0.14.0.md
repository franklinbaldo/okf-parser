# okf-parser 0.14.0

Adds the package-content phase of RFC 0003 without enabling publication.

- inspects the member list of the wheel, source distribution and both npm
  tarballs recorded in the immutable release manifest;
- requires each distribution to ship its importable modules, executables, type
  declarations, README and licence rather than metadata alone;
- rejects caches, virtual environments, editor state, credential files, private
  keys, compiled bytecode and local databases in any distribution;
- rejects source-only and development paths that belong to the repository
  instead of an installed consumer, such as TypeScript sources, test suites and
  compiler configuration inside npm tarballs;
- rejects archive members outside the expected package root, non-regular
  archive members and unsafe or traversing member names;
- excludes repository workflow automation and `.gitignore` from the Python
  source distribution;
- covers complete, incomplete, polluted and escaping archives with fixtures;
- runs `verify-contents` in the release dry run before registry preflight.

This version still has no registry write permission, OIDC publication job,
protected release environment, tag trigger or GitHub Release finalizer.
