# okf-parser 0.10.0

Adds `okf-parser-duckdb`, a separately published TypeScript adapter built on the
official promise-native `@duckdb/node-api` client.

- materializes `concepts`, `links`, `reserved`, and `diagnostics` as ordinary
  DuckDB tables;
- accepts an existing connection or creates a persistent database file;
- closes only connections created by file export, leaving caller-owned
  connections open after `attachOkf`;
- performs replacement inside a transaction;
- rejects unsafe schema identifiers and refuses to clobber existing tables
  unless overwrite is explicit;
- uses Appenders for bulk insertion and closes them before commit;
- exposes the `okf-parser-ts-duckdb` CLI;
- remains outside the main parser package so native bindings are optional;
- tests the API and packed CLI on Node 22 and 24.
