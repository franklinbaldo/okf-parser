# okf-parser 0.39.2

- adds the first experimental Rust loadable DuckDB extension slice through the C Extension API;
- exposes `okf_concepts(root)` with canonical `okf-engine` semantics and direct DuckDB data chunks;
- builds a real `.duckdb_extension` with pinned DuckDB tooling and proves it loads in DuckDB 1.5.4;
- keeps the experimental DuckDB crate outside the stable root workspace release graph.
