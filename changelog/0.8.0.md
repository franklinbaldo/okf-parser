# okf-parser 0.8.0

Promotes the JSON Schema and Zod exporters to stable cross-runtime capabilities.

- introduces one explicit Python contract graph matching the TypeScript IR;
- generates JSON Schema directly from that contract instead of treating
  Pydantic output as the interoperability boundary;
- keeps dynamic Pydantic models as an adapter over the same contract;
- makes generic `zod` the default import in both runtimes, with Astro available
  as an explicit mode;
- aligns date, datetime, unknown, optional, nullable, list, nested-object and
  Unicode-name output;
- adds a shared output corpus consumed directly by pytest and Vitest;
- marks `schema_json` and `schema_zod` stable in the capability manifest.
