# okf-parser 0.3.0

- Number ordered lists consecutively, so `1. 2. 3.` is canonical form instead of
  collapsing every marker to `1.`, keeping the source of a numbered plan
  readable in a diff.
- Strip the zero padding mdformat adds to keep marker widths even, so appending
  a tenth item no longer rewrites the nine lines above it as `01.` to `09.`.
  Each marker is matched by its literal text rather than its position, so a list
  nested in a blockquote or opening on another list's line is unpadded too,
  while a lookalike such as `01. text` inside a code block is left untouched.
- Fall back to plain numbering for a list that would overflow CommonMark's
  nine-digit marker limit, which would otherwise turn a list starting at
  `999999999` into an ordinary paragraph.
- Skip any file that no candidate form can rewrite without changing its block
  structure, rather than writing it. Formatting must never change what a
  document means.
