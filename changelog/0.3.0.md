# okf-parser 0.3.0

- Keep consecutive numbering in ordered lists, so `1. 2. 3.` is canonical form
  instead of collapsing every marker to `1.`. Both render identically, but
  consecutive numbering keeps the source of a numbered plan readable in a diff.
