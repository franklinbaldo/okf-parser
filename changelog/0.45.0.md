# okf-parser 0.45.0

- Add an opaque import `preview_token` that binds a reviewed tabular source, import options, candidate paths and current destination states.
- Let import writes accept `expected_preview_token` and fail before any filesystem mutation when the source or a relevant destination changed after preview.
- Carry the parser-owned token through the Python service, CLI and MCP write surface so consumers such as Astronauta can remain preview-first without reimplementing import state.
