# okf-parser 0.11.1

Documents the proposed production release architecture for the synchronized
Python and TypeScript distributions.

- defines one tag, one build manifest and one tested release artifact set;
- uses PyPI and npm trusted publishing through short-lived OIDC credentials;
- separates read-only preflight and build jobs from protected publication jobs;
- acknowledges that PyPI and npm cannot provide a distributed atomic
  transaction and replaces that impossible guarantee with digest-verified,
  monotonic and resumable publication;
- publishes the main npm package before its optional DuckDB adapter;
- refuses conflicting or unverifiable registry versions without mutation;
- creates the GitHub Release only after all registry artifacts verify complete;
- specifies checksums, artifact attestations, protected tags and a protected
  `release` environment;
- separates a non-publishing dry-run implementation from the later privileged
  publication workflow and one-time npm bootstrap.

This release contains the RFC only. It does not add registry credentials,
publish packages or enable a production release workflow.
