# okf-parser 0.6.0

Adds a native ESM TypeScript package alongside the Python implementation.

The new package provides an immutable library API and `okf-parser-ts` CLI for
frontmatter parsing, bundle validation, inventory, graph summaries, JSON Schema
and Zod generation. It preserves authored scalar spelling, structural nulls,
YAML merge keys, exclusion behavior, diagnostic codes, requiredness,
nullability, nullable list items and Unicode identifier collision checks.

Python and TypeScript now consume a shared language-neutral frontmatter corpus.
The exported capability manifest keeps formatter, DuckDB and MCP support
explicitly marked as not implemented rather than implying incomplete parity.
